# PHP Fundamentals - Laboratory Exercises

## Overview
This repository contains a comprehensive collection of laboratory exercises focused on PHP fundamentals. These exercises are specifically designed and tested for PHP version 8.5.4. The labs progress from basic syntax to more advanced fundamental concepts, providing a hands-on approach to learning PHP.

## Prerequisites
To run these exercises, you will need the following installed on your system:
- PHP version 8.5.4
- A terminal or command-line interface
- A code editor (e.g., VS Code, Sublime Text)
- (Optional) A local web server environment (e.g., XAMPP, MAMP) if not using the PHP built-in server.

## Repository Structure
The repository is organized into directories for each laboratory exercise:

- /lab-01-gwa-calculator: Basic GWA Calculator (utilizes PHP Classes, arrays, objects, loops, match)
